# Product Strategy

## Problem

Current AI assistants are often:

- reactive
- stateless
- detached from real workflows

## Opportunity

Transform Copilot into:

- a proactive assistant embedded in daily workflows
- a system that understands user intent over time

## Strategic Bet

We believe the winning AI assistant will:

- operate across applications
- maintain persistent user memory
- execute multi-step tasks autonomously

## Risks

- over-proactiveness can create annoyance
- memory can raise privacy concerns
- multi-step execution can introduce latency

## Mitigations

- user-controlled memory settings
- confidence thresholds for proactive suggestions
- hybrid local and cloud execution
