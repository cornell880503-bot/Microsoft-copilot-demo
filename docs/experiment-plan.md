# Experiment Plan

## Experiment 1: Proactive Suggestions

Hypothesis:

Proactive Copilot increases task completion rate.

Setup:

- control group uses reactive Copilot
- treatment group receives proactive suggestions

Success Criteria:

- 15% increase in task completion

## Experiment 2: Memory Feature

Hypothesis:

Memory improves retention.

Metrics:

- D7 retention
- repeat task efficiency

## Experiment 3: Multi-step Execution

Hypothesis:

Agent workflows reduce user effort.

Metrics:

- steps per task
- time saved
