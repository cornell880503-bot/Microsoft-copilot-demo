# Metrics Framework

## North Star Metric

Tasks completed per user per day.

## Input Metrics

- prompt-to-action conversion rate
- tool success rate
- latency per task

## Engagement Metrics

- DAU / MAU
- session length
- feature adoption rate

## Retention Metrics

- D1, D7, and D30 retention
- returning users using memory features

## Quality Metrics

- task success rate
- user satisfaction through thumbs up and thumbs down
- error rate
